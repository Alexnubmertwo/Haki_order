# Haki — POS + склад (черновая версия)

Java-приложение для точки продаж и учёта товара (приход/расход, сканирование штрих-кодов).
Одна кодовая база на Java — работает и как **веб-версия** (браузер), и как **отдельное десктоп-приложение** (окно без браузера).

Пункт «Стаканы» / «Стаканы (админ)» из меню убран, как и просили.

---

## Структура проекта

```
haki/
├── pom.xml                 ← родительский pom (сборка всех модулей разом)
├── backend/                ← Spring Boot backend + веб-интерфейс (HTML/CSS/JS)
│   └── src/main/java/com/haki/pos/...
│   └── src/main/resources/static/  ← фронтенд (index.html, css/, js/)
└── desktop/                ← JavaFX-обёртка ("приложение"-версия)
    └── src/main/java/com/haki/desktop/HakiDesktopApp.java
```

Backend хранит все данные **в памяти** (без базы данных) — так и попросили для черновой версии.
При каждом перезапуске сервера данные сбрасываются и заново заполняются демо-товарами.

## Что уже реализовано

- **Вход в систему**: экран логина при заходе на сайт — роли «Админ» и «Кассир»
  - Админ: логин `Sardor`, пароль `Sardor17` (зашит в коде для черновика)
  - Кассиры: логин/пароль создаёт админ в разделе «Кассиры»
  - Кассиру видны только рабочие разделы (Продажи, Чеки, Смены, Расходы, Приход/Расход, Клиенты) — Товары, Отчёты, Дашборд, Филиалы, Кассиры и Настройки видны только админу
- **Продажи (POS)**: категории, поиск, добавление в корзину, оплата, обновление остатков
- **Оплата**: Наличные / Карта / Смешанная / **Долг** (уходит на счёт клиента по телефону, отображается в разделе «Клиенты»)
- **Бонусный счёт клиента**: 1% кэшбэк с каждой покупки по номеру телефона, списание бонусов при следующей оплате
- **Смены**: открытие с начальной наличкой, закрытие со сверкой факт/расчёт и показом расхождения
- **Подсказка админа**: в «Настройках» можно оставить сумму+комментарий — кассир увидит её при открытии следующей смены
- **Расходы (кассовые)**: списываются из наличных текущей смены, не трогают склад
- **Приход / Расход товара**: движение товара на складе, не связано с кассой
- **Товары**: список, добавление, удаление
- **Чеки**: список всех продаж с указанием способа оплаты и клиента
- **Дашборд**: период (Сегодня/7 дней/30 дней), выручка нал/карта, вкладки по оплате, открытые смены, история смен, товары на исходе
- **Филиалы / Кассиры**: базовый CRUD
- **Гамбургер-меню**: три полоски открывают/закрывают боковую панель
- **Отчёты**: заглушка — доработаем на следующем шаге

## Как запустить веб-версию

Нужен установленный **Java 17+** и **Maven**.

```bash
cd haki/backend
mvn spring-boot:run
```

Открыть в браузере: **http://localhost:8080**

---

## Как запустить десктоп-версию (приложение, без браузера)

Сначала нужно собрать backend в локальный репозиторий Maven (десктоп-модуль его использует):

```bash
cd haki
mvn -pl backend install -DskipTests
cd desktop
mvn javafx:run
```

Откроется отдельное окно программы "Haki" — внутри работает тот же backend и тот же интерфейс, что и в вебе, просто без браузера вокруг.

> Для десктоп-версии нужен JavaFX SDK, подходящий под вашу ОС (Windows/macOS/Linux) — Maven подтянет нужные библиотеки автоматически при первом запуске (нужен интернет для скачивания зависимостей).

## Важно про эту черновую версию

- Данные **не сохраняются** между перезапусками (in-memory) — в следующей версии подключим базу данных (PostgreSQL/MySQL), как договаривались
- Нет авторизации кассиров по логину/паролю — кассир пока зафиксирован как "Владелец"
- Штрих-коды у демо-товаров сгенерированы автоматически (не настоящие) — для реальных товаров нужно будет либо ввести настоящие штрих-коды, либо распечатать свои
- Разделы «Смены», «Отчёты», «Настройки» — заготовки под следующий этап

Пишите, что доработать в первую очередь — добавление фото товаров, реальные штрих-коды,
базу данных, авторизацию кассиров, печать чеков, отчёты по сменам и т.д.
